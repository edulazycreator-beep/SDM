# SDM brand

- `sdm-logo.png`: the original logo (1000 × 1000).
- Colors: logo blue `#375C9E`, navy `#10264D`; dark-theme blue `#A9C2F4`; gradient
  `#3A60A3 → #2F5292 → #10264D` (top right to bottom left).
- `play-icon-512.png`, `play-feature-1024x500.png`: Google Play graphics.

The app's vector versions (`ic_launcher_foreground`, `ic_launcher_monochrome`,
`ic_launcher_background`, the animated `ic_splash`, `logo_body`, `logo_arrow`) were traced from the
PNG with `tools/brand/trace.py` (potracer) and written by `tools/brand/gen.py`
(`pip install potracer pillow numpy cairosvg`; run from a folder containing `src.png`).
